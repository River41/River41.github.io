Research details & results

CUHK-Shenzhen · Undergraduate Research Assistant · Nov 2024 – Apr 2025
Advisor: Tinghuan Chen · Associated paper: PCB-Migrator

Formulated placement migration as a mixed-integer linear program, encoding component positions, geometric constraints, and the objective of preserving the reference design.

Designed an LP-relaxation and iterative legalization strategy to turn candidate solutions into feasible placements.

Led algorithm design and C++ implementation, and wrote the methodology section of the paper.

Evaluation. Across 11 OpenROAD and industrial PCB benchmarks, the framework obtained legal placements using 5.56% of the MILP solver’s runtime at 110.5% of its objective cost.

Orbital: Efficient Multitenant Computing in Space

Columbia University · Graduate Research Assistant · Sep. 2025 – Apr. 2026
Advisor: Asaf Cidon

Sharing satellite compute requires knowing whether tenant tasks can meet their real-time deadlines. Orbital runs applications expressed as eBPF bytecode in a multitenant runtime. I worked on symbolic execution and cache-aware runtime estimation to support execution-time analysis for these tasks.

I built the early symbolic-execution and cache-analysis components of the eBPF runtime analyzer, using Z3 to represent register values and memory addresses and prune infeasible execution paths. I also extended the analyzer to handle supported bounded iterator loops by deriving iteration limits and transforming loop bodies into acyclic control-flow graphs.

Analysis techniques & evaluation

Symbolic execution. Implemented the depth-first analysis foundation, representing register values and memory addresses symbolically in Z3. Generated constraints for bytecode arithmetic and branches, and pruned paths with unsatisfiable branch conditions.

Cache-aware estimates. Built an early cache model that used solver queries about symbolic addresses under the current path constraints to account for memory-access costs.

Solver efficiency. Filtered relevant constraints, reused an incremental solver across branches, added constant-value fast paths, and batched candidate cache conditions. Isolated solver queries in subprocesses to enforce hard timeouts.

Bounded-loop support. Used three-color DFS to identify loop regions, derived iteration bounds for supported iterator loops, and transformed their bodies into acyclic control-flow graphs for analysis.

Team evaluation. Orbital’s final system produced execution-time bounds that were 38.6% tighter on average than prior methods. On NOEL-V with LRU caches, cache-aware bounds allowed the scheduler to admit 70% more real-time jobs than a baseline that charged every memory access as a cache miss.

LLM inference profiling with eBPF

An inference service can stall while its GPU is waiting for CPU work or communication. I contributed to event collection and timeline alignment in a profiler that brings these layers into one view, helping distinguish where time is spent.

I contributed eBPF collectors for per-thread CPU execution and run-queue waiting time, distinguishing active CPU work from scheduling delays. I paired native-function entry and exit probes to record arguments and call durations, and aligned these events with GPU and communication activity using a shared reference for eBPF and CUPTI timestamps. Together, these traces provided the context to inspect CPU work, communication calls, and GPU idle intervals in the team’s profiler.

TPU collective communication library

I started by testing the company’s in-house communication library, then contributed to diagnosis, implementation, and validation across topology discovery and data-transfer paths. The work involved both accelerator hardware and simulator configurations.

I corrected how inter-device links were classified and worked on physical-device-to-rank mapping, bandwidth-aware ring and hierarchical configurations, and direct-link and host-staged fallback paths. I also fixed a transfer-ordering bug: the sender cleared a transfer’s byte count before the receiving stage used it for a host-to-device copy. Preserving that information resolved the ordering error in the collective transfer path.

Topology, execution & debugging details

Topology correctness. Corrected the classification of links between devices so they were distinguished from a device’s own local path. Worked on mapping physical device identifiers to communication ranks and handling topology information in hardware and simulator environments.

Topology configurations. Participated in bandwidth-aware ring and hierarchical configuration work, connecting the physical interconnect graph with the settings used by collective operations.

Direct links and fallback paths. Worked on inter-device reachability, direct-link execution, and host-staged fallback logic when a direct path was unavailable.

Transfer ordering. Fixed an issue where a transfer’s byte count was cleared before the receiving stage used it for a host-to-device copy. Preserving that information addressed the ordering error in the collective transfer path.

Execution support and validation. Contributed graph-capture support and chunked execution for large collective messages, alongside testing and regression checks.

Helped deploy the library on four bare-metal machines and bring up C++ all-reduce tests over a range of message sizes. Participated in InfiniBand/SHARP integration and investigated the interactions between transport setup and communication-graph construction.

Used GDB to diagnose an initialization crash caused by a structure-layout mismatch between a framework library and the installed communication-library headers. This investigation helped motivate version-consistency checks.

Tools and data for LLM-assisted kernel development

I also worked on preparing source programs, training examples, and automated validation for a team building LLM-assisted TPU kernel generation and optimization tools.

I used Clang AST-based source reduction to prepare compact, compilable examples from historical versions of approximately 2,000 operators, and built a multi-device pipeline for correctness checks and repeated performance measurements. I also prepared training data for kernel generation, including more than 1,800 intrinsic-instruction examples, ABI validation, and deduplication.

Data pipeline, validation & collaboration

Source extraction and reduction. Processed historical versions of approximately 2,000 operators and used Clang AST-based dependency pruning to produce compact, compilable examples. One example was reduced from 3,620 lines to 100.

Automated validation. Built a multi-device test pipeline with correctness checks, repeated performance measurements, failure retries, and environment setup. The pipeline recorded more than 2,000 test runs to support example selection.

Training-data construction. Built more than 1,800 intrinsic-instruction examples, added ABI validation to kernel-synthesis examples, and used MinHash LSH for deduplication. Organized the initial supervised fine-tuning data for the team’s first training round.

Evidence and collaboration. Proposed supplying retrieved interface, shape, layout, and constraint evidence alongside a kernel-generation request. Guided two interns on testing, data preparation, and debugging the data-generation workflow.
